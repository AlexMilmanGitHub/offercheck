# offercheck skill
Install for your agent: `npx skills add AlexMilmanGitHub/offercheck`

Pay-per-call web and market-data tools for AI agents (x402, USDC on Base, no signup): https://offercheck.offercheck.workers.dev
- `/v1/read` any page as clean Markdown ($0.001)
- `/v1/verify/offer` live product price + availability with evidence ($0.01)
- `/v1/check/url` liveness, redirects, soft-404, domain age, robots policy, archive ($0.002)
- `/v1/fx` currency conversion with ECB daily reference rates ($0.002)
- `/v1/price` crypto/token prices by symbol or on-chain address ($0.002)

OpenAPI: https://offercheck.offercheck.workers.dev/openapi.json · manifest: https://offercheck.offercheck.workers.dev/.well-known/x402
